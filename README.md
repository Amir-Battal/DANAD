**DANAD** is a visually rich and modern landing page designed to represent a contemporary Arab cultural exhibition. The website focuses on storytelling through motion, typography, and strong visual identity, creating an immersive experience that reflects the depth and dynamism of modern Arab culture.

## Tech Stack

### Frontend

- React + Vite
- Lucide Icons
- GSAP
- Shadcn
- Tailwind CSS


<br/>

## Features

- 🎞️ Interactive animations powered by GSAP
- 🧠 Strong brand identity inspired by contemporary Arab culture
- 🎨 Modern visual storytelling through motion and layout
- 📱 Fully responsive landing page for all screen sizes
- 🎯 Clean, immersive, and engaging user experience
- ⚡ Smooth performance and optimized animations

<br/>

## Getting Started Locally

### 1. Clone the Repository

```bash
git clone https://github.com/Amir-Battal/DANAD.git
cd danad
```

### 2. Setup Frontend

```
npm install
npm run dev
```


<br/>

## How To Use

Open <a href="https://danad.amirbattal.com" target="_blank">DANAD</a>
Scroll through the page to experience the interactive animations
Explore the exhibition concept and cultural narrative
View event details in a visually engaging format
Access the website seamlessly on desktop or mobile devices
